ИНСТРУКЦИЯ ПО БЫСТРОМУ ДЕПЛОЮ AEGIS OS v6
=========================================

Чтобы максимально быстро запустить Aegis v6 на новом телефоне, следуйте этим шагам. Больше не нужно вводить десятки команд вручную — я создал единый скрипт установки.

1. УСТАНОВКА (Первый запуск на новом телефоне)
--------------------------------------------
Откройте Termux и вставьте эту команду (она скачает установщик и запустит его):

cd $HOME && pkg install git -y && git clone https://github.com/DeformexExx/farm.git ~/farm && cd ~/farm && chmod +x setup.sh && ./setup.sh DEV_1

**ВАЖНО:** Замените `DEV_1` на имя вашего устройства (DEV_2, DEV_3 и т.д.).

### Что сделает этот скрипт:
- Обновит системные пакеты Termux.
- Установит Python, Git, SQLite и Tsu (для Root доступа).
- Установит библиотеки для работы с Google Таблицами и Telegram.
- Настроит **Termux:Boot**, чтобы бот сам запускался при включении телефона (с правильным именем устройства и автоматическим GitHub-обновлением).

2. ПОДГОТОВКА GOOGLE SHEETS
---------------------------
Для работы бота вам нужно:
1. Создать Google Таблицу (Колонки A-E: Device_ID, Instance, Name, Status, Cookie).
2. Положить файл `creds.json` в папку `~/farm/` на телефоне.
3. Поделиться (Share) вашей таблицей с email адресом, который указан внутри `creds.json`.

3. АВТОМАТИЧЕСКИЙ СТАРТ
-----------------------
1. Установите приложение **Termux:Boot** (из F-Droid или Google Play).
2. Запустите его один раз.
3. Перезагрузите телефон.
4. После загрузки Android бот сам начнет работу через 10-20 секунд.

4. ОБНОВЛЕНИЕ КОДА
-----------------
Бот обновляется автоматически при каждой загрузке телефона (команда `git pull` встроена в загрузчик). Также вы можете нажать кнопку **🔄 UPDATE GIT** в Telegram, чтобы обновиться без перезагрузки.

ТЕХНИЧЕСКИЙ СПРАВОЧНИК
---------------------
- Путь к боту: `~/farm`
- Путь к логам: `~/farm/aegis.log`
- Путь к автозагрузке: `~/.termux/boot/aegis_start.sh`
